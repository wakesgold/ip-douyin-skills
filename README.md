# IP Douyin Skills

This repository contains a Codex skill for IP operations and Douyin content production.

## Skills

- `ip-douyin-asset-pipeline`: builds a reusable IP asset library for a business account and turns real assets into Douyin scripts, columns, captions, and reviewable content drafts.

## Mobile AI Version

- `mobile-ai-douyin-account-workflow.md`: standalone Markdown version that can be copied into mobile AI apps for users who cannot install Codex or Claude Code skills.

## Recommended Flow

Use `$ip-douyin-asset-pipeline` to collect account assets, start a Douyin account, draft content, and keep a backlog of missing account material.

## Current Domain Coverage

- General operators, creators, consultants, founders, and business owners.
- Enhanced coverage for local-life, restaurant, store-owner, and offline service accounts.

Add domain-specific references later when more fields are validated.
