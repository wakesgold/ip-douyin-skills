# IP Asset Library

Use this to build or repair the account's reusable material base before drafting content.

## Launch Modes

Do not require a long background interview before starting the account.

### Quick Launch

Use when the user wants to start now, time is limited, or the account needs first scripts before deeper asset collection.

Minimum viable fields:

- Account/IP name.
- Target user.
- Business/product problem solved.
- 1-3 real cases, proof points, or visible selling points.
- Current content goal.
- Compliance or banned-expression boundaries.

When using quick launch:

- Prefer business, product, case, and user-pain content over deep persona stories.
- Mark missing material as `待补账号资产`.
- End with 3-7 focused questions for a later account-planning session.

### Asset Completion Mode

Use when the account depends heavily on the founder/operator's trust, story, proof, speaking style, or platform sense. In this mode, ask focused collection questions, then return to scripts and columns.

## Three Libraries

### 1. Person / Founder / Operator Library

Answers: Who is this person? Why should users trust them? What is different?

| Asset | Collect | Content Use |
|---|---|---|
| Timeline | birth, growth, study, career, startup, key turns | persona story, account origin, review content |
| Proof | results, numbers, cases, certificates, media, client reviews | trust scripts, sales copy,招商话术 |
| Dark moments | failures, losses, doubt, shame, near-collapse | contrast hooks, empathy stories, values |
| Highlights | wins, breakthroughs, recognition, team success | authority, case teardown, method content |
| Key choices | why this business, why this city, why this path | founder narrative, mission, positioning |

### 2. Business Cognition Library

Answers: What views and methods does this IP own?

| Asset | Collect | Content Use |
|---|---|---|
| Industry insight | what most peers misunderstand | cognitive contrast content |
| Methodology | steps, formulas, criteria, SOPs | tutorials, courses, consulting delivery |
| Contrarian view | a judgment different from peers | viral titles, debate content |
| Failure lesson | traps and wrong decisions | avoid-pit guides, trust building |
| Conversion logic | why users buy or refuse | livestream scripts, sales copy |

### 3. Expression Style Library

Answers: How can AI sound like this person instead of generic copy?

| Asset | Collect | Use |
|---|---|---|
| Catchphrases | common wording, dialect, sentence rhythm | mouth-feel in scripts |
| Golden lines | worldview sentences | title, cover text, ending |
| Banned words | fake, grandiose, jargon-heavy, legally risky words | review and cleanup |
| Emotional tone | sharp, warm, grounded, professional, companion-like | style control |
| Signature stories | repeatable stories that represent the person | memory anchors |
