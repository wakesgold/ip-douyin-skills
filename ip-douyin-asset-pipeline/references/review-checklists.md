# Review Checklists

Use these before presenting publishable content.

## Seven Questions

| Question | Standard | Revision |
|---|---|---|
| 有没有用户思维？ | Solves a user problem, not self-expression only | Add why the user should care |
| 形容词能不能换成动词和名词？ | Avoid empty words like专业,靠谱,高级 | Replace with actions, numbers, cases |
| 用户凭什么相信？ | Has proof, data, case, or logic chain | Add real evidence |
| 每句话的目的是什么？ | Each line hooks, advances, proves, turns, or invites interaction | Delete taskless lines |
| 用户看完记住什么？ | Has a memorable label, view, or person | Add one memory point |
| 每句话是否会被转发？ | Has social currency or speaks for the user | Add user-representing sentence |
| 有没有说人话？ | No officialese, jargon pile, or condescension | Rewrite in spoken language |

## Seven Drives

At least one or two should be present. Use human motives without making the content vulgar.

| Drive | Content Signal | Angle |
|---|---|---|
| Greed | earn, save, get resources, avoid detours | “这件事帮我省了 3 年” |
| Sloth | template, shortcut, checklist, one-step clarity | “照着这 5 步做” |
| Pride | status, identity, cognitive lead | “很多同行还没看懂” |
| Anger | expose unfairness or bad industry practice | “别再被这种话术骗了” |
| Envy | desirable result or lifestyle | “普通人也能复制的关键不是运气” |
| Lust | aesthetic or sensory impact | visual cover, scene, atmosphere |
| Gluttony | strong satisfaction, complete set, binge value | “一条讲透”“全套给你” |

## Release Score

Score each out of 10. Anything below 8 needs revision.

| Dimension | Low-Score Symptom |
|---|---|
| Title | no conflict, contrast, benefit, or curiosity |
| Opening | first 3 seconds are flat |
| Structure | messy order, no turn, diary-like |
| Trust | opinions without evidence |
| Emotional release | no爽点, no user advocacy |
| Interaction | no comment, save, or forward trigger |

## Compliance and Trust

- Do not invent cases, numbers, identity titles, client results, media mentions, or credentials.
- Flag medical, financial, legal, investment, education outcome, and guaranteed-result claims.
- Replace absolute claims with verifiable specifics.
- Anonymize clients, employees, competitors, and private third parties unless the user confirms permission.
- Keep口播 natural: one idea per sentence, remove written-language stiffness, preserve the subject's real phrases.
